# Product vision

Status: planned product; no capabilities are implemented in M0.1.

TestPilot will transform API specifications and runtime observations into
evidence-backed release confidence for teams responsible for API quality.

Deterministic OpenAPI/Swagger import will supply versioned API knowledge.
A Behaviour Graph will model resources, actors, states, dependencies and
workflows. Requirements and risk assessment will inform structured executable
tests, reviewed by humans before authorized execution against real APIs.

Real HTTP evidence will support response analysis, anomaly detection and
bounded investigation. The Curiosity Engine will form hypotheses and propose
safe follow-up tests for functional, workflow, security, data-integrity and
performance concerns. Persistent project memory will preserve verified learning.

Explainable quality dimensions may include Contract Quality, Functional Quality,
Workflow Integrity, Security, Performance and Regression Stability.
Release comparison will identify changes and impacted regression coverage.
Recommendations may be RELEASE, WARN or BLOCK; humans make final release decisions.

The promise is defensible conclusions with inspectable evidence and honest
uncertainty. See [principles](principles.md) and [journey](user-journey.md).
